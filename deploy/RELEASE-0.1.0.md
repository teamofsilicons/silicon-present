## Known limits

- Linux Keynote export is unavailable. The API returns `keynote_unavailable` with HTTP 502 (the converter itself uses 501); PPTX export can be opened in Keynote. Linux Keynote import attempts a LibreOffice fallback and has fidelity limits.
- Mail is configured, but sender verification and actual delivery are unproven. Ting registration is verified; notification delivery and Accounts webhook delivery were not exercised.
- This is a single-host deployment, with brief API downtime during consistent backups. It does not establish high availability or a complete requirements audit.
- This Mac's root-owned Unbound service cached the initial negative DNS response for up to an hour. It can be refreshed by an administrator with `sudo launchctl kickstart -k system/homebrew.mxcl.unbound`; no system resolver configuration was modified by the release checks.

Detailed receipts, private runtime configuration, and exported smoke artifacts remain under ignored `.dev/production/`. Secret files have mode 0600 and must not be committed. Public verification artifacts are summarized here; no credential values are included.
